# Saif Knowledge Hub | Premier Language & Technology Academy

Official website for **Saif Knowledge Hub**, offering practical and certified training in English Communication, Office Automation, AI & Generative AI, Shopify E-Commerce, Digital Marketing, and Vocational skills.

## Features
- **Curriculum & Courses**: Comprehensive programs covering language, productivity, e-commerce, and generative AI.
- **Faculty Profiles**: Experienced instructors including Tech & AI Lead Jawad Ahmad, English Lead Fawad Saif, and MS Office Senior Instructor Abdullah Khalil.
- **Interactive Faculty Management**: In-browser management tool to customize instructor profiles and images with local persistence.
- **Responsive Modern Design**: High-performance UI built with modern HTML5, Tailwind CSS, and Material Symbols.
- **Direct Contact & Inquiries**: Integrated WhatsApp, phone, and email inquiry links for prospective students.

## Quick Start
To view locally, simply open `index.html` in any modern web browser or serve it using any static HTTP server.

## Deployment
This repository is configured for static hosting and can be served directly with:
- **GitHub Pages** (Settings > Pages > Branch: `main`, folder: `/ (root)`)
- **Vercel**
- **Netlify**
